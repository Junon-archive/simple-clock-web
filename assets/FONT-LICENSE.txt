The font is bundled for fully offline use; no external font request is made.

活動限界現在時刻待機作動中一時停止非常事態内部外部主電源供給系統提訴決議残存時間経過時間監視記録総時間開始再開初期化設定停止完了警報確認神経接続制御本部特務機関準備中解除稼働停止時間残量

Coverage: 168 unique requested Unicode code points; no missing glyphs.
To add new labels, regenerate from Japanese face 0 of the original font
using fontTools.subset, preserving the existing text and all new labels.
A WOFF2 encoder (Brotli) is needed only on the development machine.
Use TTFont(..., fontNumber=0), subset.Options with name_IDs/name_languages
set to ['*'] and name_legacy=True, Subsetter.populate(unicodes=...), then
Subsetter.subset(font). Rename name-table family/PostScript entries and
CFF family/FullName/fontNames to Eva Mincho / EvaMincho-Black, set
font.flavor='woff2', and save. Reopen the output using TTFont and compare
all required code points against font.getBestCmap() before distributing.
Preserve this notice and the complete license below with the font.
