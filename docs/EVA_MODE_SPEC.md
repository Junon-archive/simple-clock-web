# 에반게리온 모드 및 일반 화면 알림 강화 명세

작성일: 2026-11-10 · 최종 수정: 2026-11-10 · 상태: **사용자 승인 후 구현 완료**

이 문서는 기존 [기능 명세](SPEC.md)에 추가되는 후속 변경 명세다. 사용자의 명세 확인 후 `구현 진행해` 승인에 따라 에반게리온 모드와 일반 화면 알림 강화를 구현했다. 아래 명시적 변경 사항에는 이 문서를 우선하고, 나머지 동작은 기존 명세를 유지한다. 최초 명세 작성 단계의 미구현·미검증 기록은 [작업 로그](WORKLOG.md)의 과거 이력이며 현재 구현 상태와 구분한다.

## 1. 사용자 확정 요구와 설계 기본값

| 항목 | 사용자 확정 요구 |
| --- | --- |
| 일반 모드 | 화면 전체 알림을 지금보다 빠르고 뚜렷하게 깜박이도록 강화 |
| 진입 | 설정의 `에반게리온 모드`를 켜고 끄는 방식 |
| 기능 | 기존 시계·D-day·단발 타이머 기능을 유지하고 디자인 변경 |
| 시대감 | 1995년 애니메이션의 NERV 인터페이스 느낌, 영어와 일본어 한자 병기 |
| 주 사용 형태 | 여권 비율부터 휴대폰 비율 정도의 세로로 긴 작은 창 |
| 좁은 화면 | 카운트다운 중심이면서 NERV 관제실의 느낌을 유지 |
| 넓은 화면 | 큰 타이머만 확대하기보다 여러 패널을 갖춘 관제실 구성 가능 |
| 숫자 | 타이머에 밀리초까지 표시 |
| 숫자 보정 | 왼쪽 세로 세그먼트가 옆으로 밀리고 잘려 보이는 문제 수정 |
| 숫자 획 모양 | 길쭉한 숫자 비례·촘촘한 간격을 유지하며 각 획을 양끝이 뾰족한 육각형으로 변경 |
| 질감 | 제공한 레퍼런스의 영상 느낌. 숫자만 지나치게 선명하게 분리하지 않을 것 |
| 에바 완료 알림 | `非常事態 / EMERGENCY` 연출 하나로 통일. 특정 패널 안이 아닌 화면 위에서 기존 정보를 가리며 나타나고, 비상 경광등처럼 긴박한 느낌 강화 |
| 소리 | 새 소리 효과는 필요 없음 |
| 진행 단계 | 명세 작성 후 확인을 받고 구현. 이후 사용자가 구현을 승인함 |

다음은 위 요구를 구체화하여 구현한 **설계 기본값**이다. 사용자가 직접 지정한 수치와 구분한다.

- 에바 모드 기본값은 끔. 저장 후 다음 실행에도 선택을 유지한다.
- 일반 화면 알림은 `#0D0C0F ↔ #642A2E`, 1초 주기, 30회, 총 30초. 기존 원형 알림은 2초 주기 15회로 유지한다.
- 에바 완료 경보도 기존 완료 알림의 30초 지속 시간을 이어받는다. 화면 중앙에 약 -3도로 기울인 경고판, 뒤 화면 어둡게 처리, 좌우 붉은 경광등 효과와 움직이는 사선 띠를 사용한다. 1.2초 안의 두 박자를 25회 반복한다.
- 경보의 `경보 해제` 버튼과 Escape는 반복 연출만 종료하며 완료 상태를 유지한다. 이 조작과 기울기·주기·밝기는 구현 기본값이다.
- 에바 모드는 전용 소리 없이 무음으로 동작한다. 일반 모드의 기존 소리 설정 값은 보존한다.
- 밀리초는 `25:00.000`처럼 소수 세 자리. 입력 시간 단위는 기존과 같은 1~180분 정수다.
- 에바 모드에서는 원형 진행 표시를 각진 디지털 계기판과 분할 게이지로 대체한다. 남은 시간 비율의 의미는 동일하다.
- 아래 색·효과 주기·반응형 전환 기준은 구현 기본값이다. 낮은 창 보정은 최초 설계의 높이 500px 미만에서 실제 구현의 600px 이하로 확대했고, 세로 MAGI는 높이 900px 이상에서만 표시한다. 작은 창에서 숫자와 조작 공간을 확보하기 위한 조정이다.

## 3. 시각 방향

### 색과 형태

- 기본 바탕은 검정에 가까운 어두운색. 평상시 주요 정보는 황색·주황색, 보조 회로·구획에는 제한적으로 녹색·청록색을 쓴다.
- 경고의 주요 색은 빨강. EMERGENCY 글자와 사선 띠는 주황·황색과 검정을 조합한다.
- 사각 패널, 모서리를 잘라낸 프레임, 얇은 눈금, 두꺼운 구획선, 짧은 코드 표기를 일관되게 사용한다.
- 평상시 넓은 화면은 일부 프레임에 레퍼런스의 색 띠를 활용할 수 있다. 평상시 주요 숫자를 가로지르거나 화면 전체를 무지개색으로 채우지 않는다. 완료 경보는 최신 사용자 요구에 따라 별도 레이어로 기존 정보를 가린다.
- 부드러운 카드와 큰 둥근 모서리 대신 당시 계기판의 각진 구조를 사용한다. 일반 모드의 디자인에는 영향을 주지 않는다.

### 문자와 숫자

- 타이머는 세로로 긴 7세그먼트 숫자다. 최신 사용자 요청에 따라 일곱 획 모두 가운데 두께가 일정하고 양끝이 뾰족한 육각형으로 만든다. 기존 숫자 비례·숫자 사이 간격·콜론 폭은 유지한다.
- 꺼진 세그먼트는 형태만 희미하게 남겨 켜진 숫자의 실루엣을 강조한다. 구현 기본값은 폭 50·높이 112, 획 두께 10, 기울기 적용 전 획 사이 간격 약 2.1, 숫자 간 진행 폭 62, 전체 기울기 7%, 밀리초 크기 46%, 꺼진 획 불투명도 0.035다. 육각형 형태는 사용자 확정 요구이며 구체적인 치수는 구현 기본값이다.
- 좌우 세로 획은 대칭 중심선과 같은 두께·길이·끝 모양을 사용한다. 기울기는 숫자 전체에 한 번 적용하고, 왼쪽 획 좌표를 개별적으로 눌러 잘린 모양을 만들지 않는다. SVG 바깥 여백을 확보하여 첫 자리와 작은 밀리초도 잘리지 않게 한다.
- 패널 제목은 굵은 명조체 계열의 일본어 한자와 폭이 좁은 영문 대문자를 병기한다.
- 대표 문구: `活動限界 / ACTIVE TIME REMAINING`, `現在時刻 / LOCAL TIME`, `待機 / STANDBY`, `作動中 / ACTIVE`, `一時停止 / PAUSED`, `非常事態 / EMERGENCY`.
- NERV·MAGI 명칭은 계기판 표제로 활용할 수 있다. 영어·한자 표기는 실제 기능이나 상태와 연결되게 배치한다.
- 조작 이름은 짧은 영문·일본어 병기를 사용할 수 있으며 접근성 이름과 도움말은 한국어로 제공한다. 설정 항목·날짜 및 시간 입력 안내는 한국어를 유지한다.
- D-day는 기존처럼 `D-N / D-DAY / D+N`만 표시하며 행사 설명을 추가하지 않는다.

### 영상 질감

- 숫자·패널·문자 전체에 같은 정도의 미세한 입자와 약한 색 번짐을 적용한다. 숫자만 현대적인 고해상도 부품처럼 따로 보이지 않아야 한다.
- 화면에 맞게 완성된 그래픽을 약하게 촬영한 느낌을 목표로 한다. 저해상도 이미지를 강제로 확대하거나 숫자를 구별하기 어렵게 흐리는 방식은 피한다.
- 작은 숫자의 구멍·세그먼트·한자 획을 보존한다. 작은 창일수록 번짐과 입자 강도를 낮춘다.
- 상시 화면 흔들림, 강한 색 분리, 무작위 글리치, 큰 빛 번짐은 기본 효과에 넣지 않는다.
- 질감은 정적 또는 아주 미세한 효과로 구현한다. 별도의 질감 조절 UI는 첫 버전에 추가하지 않는다.

## 4. 창 크기에 따른 배치

화면 모드는 모니터 종류나 브라우저 전체화면 API 여부가 아니라 **현재 콘텐츠 영역의 너비와 높이**로 선택한다. 세로 화면을 넓은 관제실 그림의 축소판으로 만들지 않는다. 창을 늘리면 패널 수·위치·비율이 달라진다.

| 구성 | 현재 구현 기준 | 핵심 배치 |
| --- | --- | --- |
| 세로 집중형 | 너비 600px 미만, 또는 높이/너비 1.25 이상 | 카운트다운을 가장 크게, 보조 시계·D-day를 작은 상하 패널로 배치 |
| 중간 관제형 | 세로 집중형·넓은 관제형에 해당하지 않는 창 | 타이머+시간·상태의 2열 구획. 장식 패널은 줄임 |
| 넓은 관제형 | 너비 1000px 이상, 높이 650px 이상, 높이/너비 1.25 미만 | 서로 다른 크기의 여러 패널. 타이머가 한 패널을 차지하고 시계·MAGI·게이지와 균형 |
| 낮은 창 보정 | 높이 600px 이하 | 높이를 먼저 고려해 여백과 보조 패널을 줄임. 읽기 어려워지면 세로 스크롤 허용 |

이 기준은 사용자 지정 수치가 아닌 구현 기본값이다. 큰 화면에서도 숫자를 읽기 어려울 만큼 분산하지 않는다.

### 세로 집중형

```text
┌ NERV / SYSTEM STATUS ───────┐
│ 작은 날짜 · 현재 시각 · D-day │
├ 活動限界 ───────────────────┤
│ ACTIVE TIME REMAINING       │
│       24:38.127             │
│ 분할 잔여 게이지 · 상태      │
├ RESET · START/PAUSE ────────┤
│ 빠른 시작 4개               │
│ 작은 시스템 구획 · 설정      │
└────────────────────────────┘
```

- 숫자 패널에 가장 큰 면적을 배정하되, 외곽 프레임·눈금·짧은 표제만으로도 관제실의 인상을 유지한다.
- 밀리초는 분·초보다 작게 표시한다. `180:00.000`이 안 들어가는 폭에서는 밀리초를 아래 보조 줄로 옮길 수 있다. 숫자를 잘라내지 않는다.
- 세로 집중형의 MAGI는 높이 900px 이상에서만 표시한다. 높이 600px 이하에서는 세션 보조 패널을 숨겨 주 조작 공간을 확보한다. 주 조작부를 밀어낼 만큼 패널을 늘리지 않는다.
- 에바 모드에서는 대기 중에도 이 구성을 유지한다. 실행 여부 때문에 시계와 타이머 위치가 크게 바뀌지 않는다.

### 넓은 관제형

```text
┌ 活動限界 / COUNTDOWN ────┬ 現在時刻 / LOCAL TIME ──┐
│ 큰 세그먼트 카운트다운   │ 날짜 · 시계 · D-day      │
│ 잔여 게이지 · 조작       ├ STATUS / SESSION ───────┤
│                         │ 총시간 · 경과 · 잔여     │
├ MAGI / SYSTEM ───────────┼ ACTIVITY MONITOR ────────┤
│ 삼분할 상태 구획         │ 눈금 · 분할 막대 · 회로선│
└─────────────────────────┴─────────────────────────┘
```

- 레퍼런스처럼 각진 구획이 맞물리는 구성을 만든다. 같은 크기의 카드 격자를 반복하거나 중앙 숫자 하나만 확대하지 않는다.
- 보조 패널은 실제 총시간·경과 시간·남은 비율·실행 상태·PC 시각에 연결한다. 장식용 선과 코드는 조작 요소처럼 보이지 않게 한다.
- MAGI의 삼분할은 타이머·시계·알림 상태를 표현하는 모티프로 사용할 수 있다. 존재하지 않는 CPU 사용량·생체 수치·실제 장비의 전력값을 만들어 표시하지 않는다.
- 전체화면은 사용자가 브라우저 기능으로 켤 수 있다. 새 전체화면 버튼은 필수가 아니다.

### 최소 공간과 접근성

- 일반적인 세로 검증 크기: 320×450, 320×600, 390×844, 480×800.
- 추가 검증 크기: 280×400, 640×720, 800×480, 1024×768, 1440×900, 1920×1080, 1080×1920.
- 구현 검증에서는 낮은 가로 창 경계 확인을 위해 1280×600도 추가하여 총 12개 뷰포트를 사용했다.
- 가로 스크롤·주요 숫자 잘림·설정 버튼 소실은 허용하지 않는다. 최소 클릭 영역 32px를 유지한다.
- 공간이 부족하면 장식 → 보조 패널 → 여백 순으로 줄인다. 그 이후에는 읽을 수 있는 크기를 유지하고 세로 스크롤을 허용한다.
- EMERGENCY는 기존 정보와 조작부를 시각적으로 가릴 수 있다. 경보 해제 버튼은 화면 안에 유지하며, 클릭 또는 키보드로 즉시 원래 화면을 볼 수 있어야 한다. 경보 장식은 클릭을 가로채지 않고, 설정 모달이 열리면 경보보다 위에 표시한다.

## 5. 기존 기능과 테마의 관계

- 설정에 `에반게리온 모드` 스위치를 추가한다. 기존 설정처럼 저장 시 적용하고, 취소하면 원래 모드를 유지한다.
- 테마 선택은 `evaMode: boolean` 필드에 저장하며 기존 데이터나 잘못된 값에서는 일반 모드(`false`)를 기본으로 한다.
- 시계·날짜·D-day, 빠른 시작 4개, 직접 시간 입력, 일시정지·재개·초기화, 로컬 저장, 종료·절전 후 수동 이어가기는 동일하게 제공한다.
- 일반/에바 사이 전환으로 타이머 상태·총시간·남은 시간·선택한 시간·D-day를 초기화하지 않는다. 타이머 상태와 완료 판정을 수행하는 엔진을 중복 생성하지 않는다. 밀리초 표시를 위한 별도 화면 렌더 루프는 허용한다.
- 에바 모드에서 기존 `원형 / 화면` 알림 토글은 숨긴다. 기존 `alertMode` 값은 보존하고 일반 모드로 돌아가면 다시 표시한다.
- 설정의 `완료 시각 알림`은 두 테마 공통이다. 꺼져 있으면 반복 연출만 생략하고, 완료 상태는 정적인 문구로 표시한다.
- 에바 모드는 무음이라는 설계 기본값을 적용한다. 기존 `soundEnabled` 값은 변경하지 않는다. 설정의 소리 항목은 에바 모드에서 비활성화하고 `에바 모드에서는 무음`을 안내한다.
- 완료 도중 테마를 바꿔도 최초 완료 시각부터 30초라는 종료 기준을 유지한다. 전환만으로 효과나 소리를 새로 발생시키지 않는다.
- 완료 효과가 이미 끝났거나 꺼진 상태라면 테마 전환으로 다시 재생하지 않는다. 새 타이머 완료 때만 새 30초 효과를 시작한다.

## 6. 밀리초 카운트다운

- 에바 모드의 표기는 SVG 7세그먼트의 `분:초.밀리초`, 예: `25:00.000`, `04:59.872`, `180:00.000`. 일반 모드의 기존 분·초 표기는 유지한다.
- 밀리초는 실제 남은 시간에서 계산한다. 무작위 숫자나 별도 장식 카운터를 사용하지 않는다.
- 입력 시간은 기존대로 분 단위이며, 밀리초 입력 기능을 추가하지 않는다.
- 일시정지하면 세 자리 소수부와 진행 게이지도 같은 시점에서 정지한다. 재개하면 그 값에서 이어진다.
- 화면 갱신은 브라우저 프레임에 맞춘다. 1,000회/초 렌더링이나 모든 밀리초 숫자가 화면에 한 번씩 보이는 것을 요구하지 않는다.
- 고빈도 표시는 실행 중 보이는 숫자·게이지에 한정한다. 대기·일시정지·숨김 상태에는 불필요한 프레임 작업을 멈춘다.
- 렌더링과 기존 실행 공백 감지를 구분한다. 숨김·절전 후 복귀할 때 중단 여부를 먼저 확인하고, 큰 공백을 표시 잔여량에서 먼저 빼지 않는다.
- 완료 판정은 공유 타이머 상태에서 한 번만 발생한다. 숫자는 음수가 되지 않고 완료 시 `00:00.000`으로 고정된다. 렌더 루프가 별도로 완료 알림을 중복 실행하지 않는다.
- 세그먼트가 시각 표현이더라도 접근성용 시간 값은 제공한다. 밀리초 변화를 매 프레임 음성으로 알리지 않는다.

## 7. 완료 연출

### 7.1 일반 모드의 화면 알림 강화

- 변경 대상은 일반 모드의 **화면** 알림이다. 원형의 은은한 테두리 효과는 유지한다.
- 기존 2초의 부드러운 왕복에서, **1초 주기 30회**의 더 명확한 점멸로 바꾼다.
- 배경색은 `#0D0C0F ↔ #642A2E`. 이전보다 색 차이를 키우되 흰색 플래시나 밝은 단색 전면 점멸은 사용하지 않는다.
- 주기 안에 검정 유지·짧은 전환·붉은색 유지·짧은 복귀 구간을 둔다. 구현값은 0~35% 검정, 35~45% 전환, 45~85% 붉은색, 85~100% 검정으로 복귀다.
- 시계 숫자와 버튼은 그대로 유지하고 페이지 배경만 바뀐다. 30초가 지나면 기본 검정 배경으로 돌아간다.
- 기존의 선택 저장, 효과 중 토글, 공통 끄기, reduced motion, 새로고침 후 재생 금지 정책을 유지한다.

### 7.2 에바 모드의 EMERGENCY

- 완료 순간 패널의 주요 강조색을 빨강으로 바꾸고 `非常事態 / EMERGENCY`와 노랑·검정 사선 띠를 크게 표시한다.
- 최신 사용자 요청에 따라 **화면 위에서 다른 정보를 가리는 경보 레이어**로 표시한다. 이전의 ‘특정 패널 중심·주요 숫자와 조작부를 덮지 않음’ 배치는 폐기한다. 세로·가로 모두 같은 방식으로 화면 중앙의 큰 경고판이 기존 관제실 위를 가로막는다.
- 레이어는 `body` 직계의 고정 배치로 창 전체에 붙인다. 대시보드의 필터·그리드 구획에 종속되지 않고, 작은 창을 스크롤해도 화면 위에 머무른다. 약 -3도 기울인 경고판과 어둡게 보이는 뒤 화면으로 앞뒤 깊이를 표현한다.
- 작은 창에서도 `EMERGENCY`와 경보 해제 버튼은 읽고 조작할 수 있어야 한다. 경고 장식은 클릭을 가로채지 않고 해제 버튼만 클릭을 받는다. 설정 모달은 브라우저 최상위 레이어에서 경보보다 위에 표시한다.
- 기본 동적 연출은 **1.2초 안의 두 박자를 25회**, 총 30초다. 좌우 붉은 경광등 효과가 교대하고, 경고판 밝기는 `0.65 → 1` 범위에서 두 번 강조되며, 위·아래 사선 띠는 반대 방향으로 움직인다. 배경 강조는 `#190A09 ↔ #541612`를 사용한다. 완료 시각에서 계산한 공통 지연값으로 테마를 전환해도 연출 위상과 종료 시각을 유지한다.
- 표현의 강도는 큰 글자·색 변화·사선 띠·패널 전환에서 얻는다. 빠른 흰색 플래시나 화면 전체를 흔드는 효과는 넣지 않는다.
- 최초 완료부터 30초 후 전체 경보 레이어와 반복 효과를 없앤다. 이후에는 원래 어두운 패널 배경과 작은 정적 `非常事態 / EMERGENCY` 완료 표식, `00:00.000`을 유지한다.
- `경보 해제` 클릭·포커스 후 Enter 또는 Escape로 30초 전에 해제할 수 있다. 해제는 완료 상태를 초기화하거나 새 타이머를 시작하지 않는다. 해제 버튼에 있던 포커스는 타이머 시작 버튼으로 돌린다.
- 설정 모달·타이머 입력·D-day 입력에서 Escape는 해당 창의 취소·닫기 역할을 유지하고, 같은 키 입력으로 뒤의 경보를 함께 해제하지 않는다.
- 다음 타이머 시작·초기화·새 시간 확정 시 모든 비상 표현을 제거한다.
- `완료 시각 알림`이 꺼져 있거나 `prefers-reduced-motion: reduce`이면 처음부터 정적인 완료 표식을 사용한다. 설정을 다시 켜거나 테마를 전환해도 종료된 연출을 재생하지 않는다.
- 효과 중 절전·긴 실행 공백·페이지 이탈을 감지하면 반복 효과를 끝내고 정적 완료 상태로 둔다. 기존 저장·복원 정책을 공유한다.
- 완료 이전의 자동 경고 단계나 남은 10초 사이렌 등은 이번 범위에 추가하지 않는다.

## 8. 구현 범위와 자산

- 기본 실행은 기존 `index.html`의 `file://` 직접 실행이다. 서버·호스팅·설치·네트워크 호출을 요구하지 않는다.
- 세그먼트 숫자·프레임·사선 띠·게이지·MAGI 모티프는 CSS/SVG 등 코드 기반으로 구성할 수 있다.

- 테마 스타일은 `eva.css`에 분리하여 일반 화면에 새어 나오지 않게 한다. 시계·타이머·저장 엔진과 SVG 렌더링은 기존 `app.js`에 두고 프레임워크·빌드 도구는 도입하지 않는다.
- 실행 파일을 옮길 때는 `index.html`, `styles.css`, `eva.css`, `app.js`, `assets/`를 함께 복사하여 상대 경로를 유지한다. 폰트와 함께 라이선스 파일도 보존한다.
- 새 기능으로 통계·휴식 반복·외부 서비스·캐릭터 배경·오디오 라이브러리를 추가하지 않는다.

이 절은 화면 위 경보와 숫자 도형 보정 전의 결과다. 특히 이전 경보의 1초 주기·밝기·배치 확인을 현재 구현의 검증으로 해석하지 않는다.

- Linux Chrome 146에서 임시 HTTP 서버로 대체하지 않고 실제 `file://`로 실행했다. 핵심 로직 14/14, 기존 브라우저 시나리오 18/18, 에바 브라우저 검증 11/11 그룹을 통과했다. 외부 HTTP(S) 요청과 처리되지 않은 JavaScript 오류는 각각 0건이다.
- E01~E15의 기능 동작을 설정 저장·취소·복원, 상태별 테마 전환, 밀리초 정지·재개, 실행 공백 주입, 입력·키보드 조작, 무음·옵션 보존, 최초 완료 기준 30초 유지, 효과 중단·재생 금지 시나리오로 확인했다. 브라우저 시나리오의 11개 그룹은 인수 기준 17개와 일대일 대응하는 개수가 아니다.
- E03~E06은 명세의 11개 크기와 추가 1280×600, 총 12개 뷰포트에서 화면·숫자·조작부·작은 설정 창을 확인했다. 최소 1분부터 최대 180분의 숫자 폭을 점검했다.
- 당시 E12·E14는 실제 시간으로 30초 경과 후 모든 완료 애니메이션이 0개가 되고 정적 완료 표식이 유지되는 것을 추가 확인했다. 당시의 1초 주기 CSS에서 배경 `(9, 11, 9) → (87, 26, 21)`·경고 띠 밝기 `0.45 → 1`·조작부를 덮지 않는 배치를 확인했다. 현재 경보는 7.2절의 별도 화면 레이어와 1.2초 두 박자 기준으로 바뀌었다.
- 당시 E16의 세로·넓은 관제실·경보 캡처를 생성하고 직접 확인했다. `docs/`의 미리보기 파일은 최신 구현으로 교체하므로 과거 화면을 보존한 자료로 간주하지 않는다. 실제 모니터의 주변 시야 인지성은 별도 확인이 필요하다.
- E17은 오프라인 실행·로컬 자산 경로·숨김/일시정지 시 고빈도 렌더 중단 범위를 확인했다. 실제 `file://` 글꼴 로드를 확인했고, 글꼴을 뺀 임시 복사본에서도 대체 표시와 타이머가 동작했다. **장시간 상시 표시 전체를 통과 처리하지 않는다.** 실물 모니터·실제 OS 절전·장시간 피로감·다른 운영체제·Edge는 미검증이다.

### 2026-11-10 세그먼트 보정·화면 경보 수정 검증

- 숫자 도형은 Chrome 146의 실제 `file://`에서 280×400·390×844·1440×900으로 `02:46.890`과 `180:00.000`을 확인했다. 왼쪽·오른쪽 세로 획은 같은 10×32 도형이며 모든 꼭짓점이 SVG 표시 영역 안에 있고 가로 넘침·JavaScript 오류가 없었다. 핵심 로직 14/14와 구문 검사를 통과했다.
- 화면 경보 변경 후 Linux Chrome **146.0.7680.177**의 실제 `file://`에서 핵심 로직 **14/14**, 기존 브라우저 **18/18**, 에바 브라우저 **12/12 그룹**을 통과했다. 외부 HTTP(S) 요청·처리되지 않은 JavaScript 오류는 0건이다.
- 기존 12개 뷰포트의 화면·설정 배치와 280×400·320×450·800×480·1440×900의 경보 레이어를 확인했다. 스크롤 중 화면 고정, 리사이즈, 경보 전후 기존 화면 배치 유지, 설정 모달의 우선 표시, 경보 해제 클릭·Enter·Escape, 날짜·시간 편집 Escape의 기존 역할을 확인했다. 이전 11개 그룹 통과 기록과 이번 12개 그룹 검증은 구분한다.
- 실제 CSS 위상 120·420·720ms에서 좌우 경광등 불투명도는 `(0.95, 0.12) → (0.12, 0.12) → (0.12, 0.95)`, 경고판 밝기는 `1 → 0.65 → 1`, 사선 띠 위치는 `4.8 → 16.8 → 28.8px`로 변했다. 여섯 애니메이션의 총 길이는 각각 30,000ms였다. 가상 시간 외에 **실제 30초 경과** 후 경보 레이어 숨김·애니메이션 0개·완료 상태 유지를 확인했다.
