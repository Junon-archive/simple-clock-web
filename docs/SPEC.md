# 로컬 시계·단발 타이머 구현 명세

작성일: 2026-11-09 · 최종 수정: 2026-11-10 · 상태: 기본 기능·에반게리온 모드 구현 완료, 실제 PC 절전 검증 대기

후속 변경: [에반게리온 모드 및 일반 화면 알림 강화](EVA_MODE_SPEC.md)는 사용자 승인 후 구현되었다. 명시된 테마·밀리초·완료 연출 변경에는 후속 명세를 적용하고, 공유 시계·타이머·저장 동작에는 이 명세를 적용한다. 아래 일반 화면 구성과 에바 화면 구성은 같은 타이머 상태를 사용한다.

## 1. 목적과 확정 사항

연구실 PC의 작은 보조 모니터를 세 영역으로 사용할 때, 가운데 브라우저 창에 상시 표시하는 시계와 단발 집중 타이머를 만든다. 실제 모니터와 창의 크기는 미정이다.

### 사용자가 확정한 요구

| 항목 | 결정 |
| --- | --- |
| 실행 | 개인용 로컬 브라우저 화면. 호스팅 불필요 |
| 크기 | 특정 해상도에 고정하지 않고 창 크기에 동적으로 대응 |
| 디자인 | `reference/미니멀 로컬 시계와 포모도로 대시보드.png` 참고 |
| 시간 기준 | PC 시스템 시간 |
| D-day | 설명 없이 날짜 차이만 표시. 더블클릭으로 바로 수정 |
| 타이머 | 집중·휴식 반복 없는 단발 타이머 |
| 빠른 시작 | 시작 전에 3~4개 시간 버튼. 설정에서 시간 변경 |
| 원형 진행률 | 선택한 총시간이 항상 360도. 남은 시간 비율만큼 감소 |
| 완료 알림 | 시작·일시정지 오른쪽 토글로 원형 또는 화면 배경 알림 선택. 두 모드 모두 30초 후 종료, 선택 유지. 화면 모드는 주변 시야에서도 인지할 수 있으면서 눈부시지 않을 것 |
| 종료·절전 | 진행을 중단하고 복귀 후 사용자가 수동으로 다시 시작 |
| 설정 | 하단의 작은 톱니바퀴. 시계 초 표시 켜기·끄기 및 관련 설정 |
| 에반게리온 모드 | 설정에서 전환하는 1995년 NERV풍 디자인. 영어·한자 병기, 밀리초 카운트다운, 크기별 관제실 구성, 전용 EMERGENCY 연출. 상세 기준은 후속 명세 |

### 명세에서 정한 기본값

- 실행 진입점은 `index.html`, 실행 방식은 파일 더블클릭이다.
- 종료·절전의 ‘중단’은 **남은 시간을 보존한 일시정지**로 해석한다. 이어서 시작과 처음부터 시작을 구분한다.
- 기본 타이머 25분, 빠른 시작 버튼 4개: 10분·20분·25분·60분.
- 24시간제, 시스템 현지 날짜·시간대, 영어 대문자 요일.
- 시계 초 표시 켬, D-day 표시 켬, 완료 시각 알림 켬, 기본 알림 모드 원형, 완료 소리 끔.
- 알림의 구체적인 색과 주기는 구현 기본값이다. 일반 화면 배경은 `#0D0C0F ↔ #642A2E`, 1초 주기 30회로 점멸한다. 원형은 기존 2초 주기 15회와 `ease-in-out`을 유지한다. 사용자가 확정한 일반 완료 알림 지속 시간은 두 방식 모두 30초다.
- 에반게리온 모드 기본값은 끔이며 선택을 저장한다. 전용 EMERGENCY는 무음·30초로 구현하고 일반 알림 방식·소리 옵션은 보존한다.
- 시간 입력은 1~180분의 정수. 이 범위와 값은 사용자 확정 요구가 아닌 구현 기본값이다.

범위에는 Discord 임베드, AI 구독 사용량, 화면 3분할 제어, 자동 휴식, 통계, 계정, 동기화, 서버, 배포를 포함하지 않는다.

## 2. 시각 구성

### 2.1 레퍼런스 적용

검정에 가까운 배경, 따뜻한 아이보리 숫자, 회색 보조 정보, 부드러운 빨강 포인트를 사용한다. 아래 값은 출발점이며 실제 이미지와 화면을 비교하며 조정할 수 있다.

| 역할 | 권장 색상 |
| --- | --- |
| 배경 | `#0D0C0F` |
| 주요 숫자 | `#F5F0E4` |
| 보조 글자 | `#AAA7A9` |
| 빨강 포인트 | `#EF5B57` |
| 진행 원의 빈 트랙 | `#352022` |
| 구분선 | `#555255` |

기본 배치는 위에서 아래 순서로 유지한다.

1. `2026.11.09 MON` 형식의 날짜.
2. 빨간 `D-14` 형식의 D-day.
3. 가장 큰 `14:32` 시계와 우측 하단의 작은 `08` 초.
4. 얇은 가로 구분선.
5. 작은 상태 문구: `READY` / `FOCUS` / `PAUSED` / `DONE`.
6. 원형 타이머: 가운데 남은 `24:38`, 그 아래 작은 `of 25:00`.
7. 중앙 시작·일시정지 버튼, 왼쪽 작은 초기화 아이콘, 오른쪽 원형/화면 알림 모드 토글.
8. 대기·완료 상태에서 빠른 시작 시간 버튼.
9. 하단의 작은 설정 톱니바퀴.

단발 타이머이므로 이미지의 다음 구간 버튼, 회차 점 4개, `25 / 5` 표시는 제거한다. 큰 시계와 원형 타이머의 시각적 위계는 유지한다.

일반 모드에서는 이미지의 질감·번짐을 필수 요소로 취급하지 않는다. 평면적인 배경, 선명한 숫자, 얇은 선을 우선한다. 카드 테두리, 강한 그림자, 네온 효과, 장식용 그라데이션은 추가하지 않는다. 에바 모드의 각진 패널·영상 질감·글꼴·반응형 배치는 후속 명세를 따른다.

### 2.2 반응형

- 브라우저 콘텐츠 영역을 기준으로 가로와 세로 공간을 함께 고려한다. 창 너비만으로 전체 화면을 확대하지 않는다.
- 가로형 창에서도 기본적인 상하 배치를 유지하고, 가운데 정렬과 적절한 최대 너비로 좌우 여백을 둔다.
- 시계 숫자·원 지름·여백이 연동되어 줄어들게 한다. 원은 항상 원이며 타원이 되지 않는다.
- `font-variant-numeric: tabular-nums`와 고정된 숫자 자리로 매초 레이아웃이 흔들리지 않게 한다. 콜론은 깜박이지 않는다.
- 초 표시를 꺼도 시·분의 위치와 크기는 유지한다. 초 자리는 보이지 않는 공간으로 남겨도 된다.
- 기본 화면 검증 크기(CSS px): `320×600`, `480×800`, `640×720`, `800×480`, `1122×1402`.
- 위 크기의 100% 배율에서는 핵심 정보·버튼·톱니바퀴가 겹치거나 잘리지 않고, 본문 스크롤 없이 표시되도록 한다.
- 그보다 작은 창이나 높은 브라우저 확대 배율에서는 가독성을 과도하게 희생하지 말고 세로 스크롤을 허용한다. 가로 스크롤과 숨겨진 설정 버튼은 피한다.
- 설정 창은 작은 뷰포트에서 내부 세로 스크롤을 허용한다. 저장·취소를 항상 접근할 수 있게 한다.

### 2.3 조작과 접근성

- 아이콘은 인라인 SVG 등을 사용한다. 운영체제별 외형이 달라지는 이모지 아이콘은 사용하지 않는다.
- 버튼은 실제 `button` 요소로 구현하고, 작은 아이콘에도 최소 32×32 CSS px의 클릭 영역을 둔다.
- 키보드 포커스를 표시하고 아이콘 버튼에 한국어 접근성 이름과 툴팁을 제공한다.
- 설정과 날짜 입력은 한국어, 메인 상태 문구는 위의 짧은 영어로 통일한다.
- 매초 시각적으로 갱신되는 숫자를 스크린리더로 매번 읽지 않는다. 완료·일시정지 같은 상태 변경만 알린다.

## 3. 시계와 날짜

- 실제 `Date` 값으로 PC 현지 날짜·시간을 표시한다. 인터넷 시간 API를 호출하지 않는다.
- 날짜 형식은 `YYYY.MM.DD DDD`, 시계는 두 자리 `HH:mm`, 초는 두 자리 `ss`다.
- 초는 설정에서 켜고 끈다. 시계 초를 꺼도 타이머의 초는 계속 표시한다.
- 자정, 창 복귀, 시스템 시간·시간대 변경 시 다음 갱신에서 현재 값으로 맞춘다.
- 콜백마다 숫자에 1을 더하는 방식으로 시간을 누적하지 않는다.

## 4. D-day

- 목표 날짜까지의 **현지 달력 날짜 차이**를 표시한다. 목표 행사명·설명은 표시하지 않는다.
- 미래 `D-14`, 당일 `D-DAY`, 과거 `D+1`. 날짜가 없으면 편집 가능한 `D-—`를 표시하며 임의 목표일을 만들지 않는다.
- 초기에는 표시가 켜져 있다. 설정에서 표시를 끄면 해당 행을 접어 공간을 돌려준다.
- D-day를 더블클릭하면 그 위치에 날짜 입력과 작은 저장·취소 조작을 표시한다. 별도 페이지나 브라우저 `prompt()`로 이동하지 않는다.
- 현재 날짜 값을 채워 넣고 즉시 입력에 포커스를 준다. 미설정일 때는 오늘을 편집 초깃값으로 제안하되 저장하기 전까지 확정하지 않는다.
- Enter 또는 저장으로 확정, Escape 또는 취소로 기존 값 복원. 포커스가 빠졌다는 이유만으로 자동 저장하지 않는다.
- 키보드 사용자는 D-day에 포커스 후 Enter로 같은 편집을 열 수 있다. 설정 창에서도 날짜를 바꿀 수 있다.
- 유효하지 않은 날짜는 저장하지 않고 입력 근처에 짧게 안내한다. 목표 날짜 삭제는 설정에서 제공한다.
- 날짜 계산은 각 날짜의 현지 연·월·일을 달력 일수로 정규화해 비교한다. `YYYY-MM-DD` 문자열을 UTC 시각으로 그대로 읽거나, 현지 자정 간 밀리초를 단순히 24시간으로 나누어 DST 오차를 만들지 않는다.

## 5. 단발 타이머

### 5.1 빠른 시작과 표시

- `idle`과 `completed`에서 원 아래에 빠른 시작 버튼 4개를 표시한다.
- 기본 라벨은 `10분`, `20분`, `25분`, `1시간`. 60의 배수는 시간으로, 그 외는 분으로 표시한다.
- 한 번 클릭하면 해당 시간으로 새 타이머를 즉시 시작한다. 시간 선택 후 추가 시작 클릭을 요구하지 않는다.
- 실행·일시정지 중에는 빠른 시작 버튼을 숨긴다. 초기화 후 다른 시간을 선택할 수 있다.
- 숨김 전후 큰 시계와 원이 뛰지 않게 버튼 행의 공간을 유지한다. 좁은 창에서는 2×2 배치 가능하다.
- 남은 시간은 `ceil(remainingMs / 1000)`의 `분:두 자리 초` 형식이다. 분은 최소 두 자리이며 60분은 `60:00`, 180분은 `180:00`이다.
- `of 25:00`은 해당 실행의 최초 총시간이다. 일시정지·재개해도 바뀌지 않는다.

### 5.2 원형 진행률

- `progress = clamp(remainingMs / durationMs, 0, 1)`.
- 어떤 시간을 선택해도 시작은 100%인 완전한 원이다. 30분 시작도 360도, 15분 남으면 180도, 완료하면 0도다.
- 12시 방향부터 시간이 지난 부분이 **반시계 방향**으로 비워진다. 예를 들어 25% 경과 시 왼쪽 위 1/4이 비고, 남은 호는 12시부터 시계 방향으로 3/4을 차지한다.
- 진행 호와 어두운 전체 트랙을 분리한다. 일시정지하면 호도 멈춘다.
- 진행 표시에는 실제 남은 밀리초를 사용한다. 표시 문자열의 반올림으로 진행률을 계산하지 않는다.
- SVG 사용을 권장한다. 애니메이션이 상태 계산의 기준이 되어서는 안 된다.

### 5.3 상태와 조작

- 타이머 숫자를 한 번 클릭하거나 키보드로 선택 후 Enter를 누르면 원 안에서 시간을 직접 입력할 수 있다. 입력값은 현재 총시간을 기준으로 한 1~180분 정수다.
- 설정 버튼 또는 Enter로 확정하면 새 총시간의 `idle`로 전환하고 진행 원을 100%로 복원한다. 실행 중·일시정지·완료 상태에서도 동일하며, 완료 효과는 중단한다. 자동 시작하지 않는다.
- 취소·Escape는 입력을 버린다. 편집창을 여는 것만으로 기존 타이머를 멈추지 않는다. 빠른 시작·초기화·다른 편집창 열기는 미저장 입력을 닫는다.
- 직접 설정한 시간은 타이머 스냅샷에 저장하되 설정의 기본 시간·빠른 시작 값은 바꾸지 않는다.

| 상태 | 화면 | 중앙 버튼 | 초기화 | 빠른 시작 |
| --- | --- | --- | --- | --- |
| `idle` | `READY`, 선택된 총시간, 전체 원 | 시작 | 비활성 | 표시 |
| `running` | `FOCUS`, 줄어드는 시간·호 | 일시정지 | 동일 총시간의 `idle`로 | 숨김 |
| `paused` | `PAUSED`, 보존된 시간·호 | 이어서 시작 | 동일 총시간의 `idle`로 | 숨김 |
| `completed` | `DONE`, `00:00`, 완료 표시 | 같은 시간으로 다시 시작 | 동일 총시간의 `idle`로 | 표시 |

- 첫 실행의 선택 시간은 설정의 기본 타이머 시간이다.
- 빠른 시작은 해당 실행의 선택 시간과 총시간을 바꾼다. 설정의 기본 시간까지 바꾸지는 않는다.
- 중앙 재시작 버튼과 빠른 시작으로 새 타이머를 시작하면 이전 완료 효과를 즉시 제거한다.
- `running → paused → running`의 재개는 남은 시간을 이어서 센다. 원 비율의 분모는 최초 총시간을 유지한다.
- `running → completed`는 남은 시간이 0에 도달한 순간 딱 한 번 발생한다. 음수 시간·중복 완료 이벤트를 만들지 않는다.
- 설정이나 D-day 편집창을 여는 것만으로 타이머를 멈추지 않는다.
- 초기화는 작고 분리된 버튼으로 제공한다. 클릭 후 추가 확인창은 띄우지 않는다.
- 반복 클릭, 창 크기 변경, 설정 저장으로 중복 타이머 루프가 생기지 않게 한다.

### 5.4 완료 알림 모드와 30초 효과

이 절의 원형/화면 선택은 일반 모드에 적용한다. 에바 모드에서는 전용 EMERGENCY를 사용하되 완료 시각, 30초 종료 기준, 중단·재생 금지 정책은 공유한다.

- 시작·일시정지 버튼 오른쪽에 원형/화면 모드 토글을 둔다. 버튼 안에는 글자 없이 선택한 모드의 아이콘만 표시하고, 툴팁과 접근성 이름·상태를 유지한다. 키보드로도 전환할 수 있다.
- 토글은 모드 선택만 담당하고 변경 즉시 저장한다. 설정 창의 공통 완료 시각 알림(`pulseEnabled`)이 꺼져 있으면 모드를 바꿔도 이를 켜지 않는다.
- 실행·일시정지·대기 중 토글은 총시간·남은 시간·타이머 상태에 영향을 주지 않는다. 완료 시점에 선택된 모드를 적용한다.
- **원형 모드(`ring`, 기본값):** 완료 순간 진행 호는 0이므로 완료 표시용 전체 원형 테두리를 별도로 표시한다. 이 테두리만 평소 포인트 색의 밝기 → 더 어두운 밝기 → 평소 밝기로 변한다. 구현 기본값은 불투명도 `1 → 0.35 → 1`이며 최댓값은 평상시 밝기를 넘지 않는다.
- **화면 모드(`screen`):** 페이지 전체 배경만 검정에 가까운 기본색 `#0D0C0F` → 어두운 붉은색 `#642A2E` → 기본색으로 변한다. `html` 배경을 사용해 창 전체의 콘텐츠 영역에 적용하며, 숫자·버튼·원 테두리의 밝기와 크기는 고정한다.
- 두 모드 모두 처음 완료된 시점부터 **30초** 동안 동작한다. 원형은 2초 주기 15회와 `ease-in-out`을 유지하고, 화면은 1초 주기 30회로 검정 유지·짧은 전환·붉은색 유지·복귀를 반복한다. 흰색 플래시, 강한 발광 효과, 숫자 깜박임은 사용하지 않는다.
- 효과가 진행되는 동안 모드를 바꾸면 최초 완료 시점과 애니메이션 진행 위치를 유지한 채 남은 구간만 새 모드로 표시한다. 30초를 새로 세거나 소리를 추가 재생하지 않는다. 예를 들어 완료 20초 후 전환하면 10초 뒤 끝난다.
- 완료 시간은 `00:00`, 상태는 `DONE`으로 고정한다. 30초 후 원은 어두운 정적 테두리, 페이지는 기본 배경색으로 돌아가며 `completed` 상태를 유지한다. 효과가 끝난 뒤 토글을 바꾸어도 다시 재생하지 않는다.
- 초기화·새 시작·직접 시간 설정·완료 시각 알림 끄기·페이지 이탈·실행 공백 감지는 두 모드의 효과와 애니메이션 지연값을 모두 제거한다. 타이머가 여전히 완료 상태라면 `DONE`과 `00:00`은 유지한다.
- `prefers-reduced-motion: reduce`에서는 두 모드의 반복 변화를 생략한다. 효과 도중 이 설정이 켜져도 즉시 정적 완료 상태와 기본 배경으로 돌아간다. 다시 해제하거나 시각 알림을 다시 켠다고 중단된 효과를 재생하지 않는다.
- 완료 후 새로고침·재접속 시 선택 모드는 복원하지만 효과나 소리를 다시 재생하지 않는다.
- 기본은 무음. 완료 소리를 켰다면 완료 진입 시에만 작고 짧은 소리를 한 번 재생한다. 반복 알람은 없다.

## 6. 종료·절전·시간 정확도

### 6.1 사용자에게 보이는 동작

- 창 닫기, 새로고침, 브라우저 재시작 후 진행 중이던 타이머는 **남은 시간을 보존한 `paused`**로 복원한다.
- 닫혀 있던 시간은 차감하지 않는다. 복원 직후 자동 재생·완료 처리를 하지 않는다.
- PC 절전이나 실행 중단을 감지하면 마지막 정상 관측의 남은 시간으로 `paused`가 된다. 사용자가 이어서 시작을 눌러야 한다.
- 다른 앱을 클릭해 브라우저 포커스를 잃었다는 이유만으로 멈추지 않는다. 보조 모니터에 표시한 상태로 다른 작업을 할 수 있어야 한다.
- 탭 숨김 자체는 절전으로 간주하지 않는다. 다만 브라우저가 숨겨진 탭의 실행을 오래 멈추면 아래의 공백 감지 정책에 의해 일시정지할 수 있다.

### 6.2 구현 기준과 한계

이 절은 순수 로컬 브라우저에서 사용자 요구를 최대한 일관되게 구현하기 위한 정책이다. 운영체제의 절전 시작 시각을 정확히 받는다고 가정하지 않는다.

- 일반 실행 중 경과 시간은 `performance.now()` 기반으로 계산한다. 콜백 호출 횟수마다 1초를 빼지 않는다.
- 약 250~500ms 간격의 관측 루프에서 이전 관측과 현재의 monotonic 시간 차이 및 `Date.now()` 차이를 함께 확인한다. 렌더링용 `requestAnimationFrame`과 공백 판정 루프를 혼동하지 않는다.
- 최초 기준은 **3,000ms를 초과하는 관측 공백** 또는 두 시간 차이의 **3,000ms 초과 불일치**다. 하나라도 감지하면 시간 차감·완료 판정보다 먼저 일시정지하고 마지막 정상 관측값을 보존한다.
- 시스템 시각이 크게 바뀌어도 타이머를 급격히 소진·연장하지 않는다. 이 경우에도 보수적으로 일시정지할 수 있다. 시계 표시는 변경된 시스템 시간을 따른다.
- 브라우저의 freeze 등 생명주기 이벤트를 사용할 수 있으면 보조 수단으로 사용하되 필수 지원으로 가정하지 않는다. 복귀 시에도 공백 검사 후 화면을 갱신한다.
- 절전과 브라우저의 장시간 실행 억제를 완전히 구별할 수 없으며, 짧은 중단은 임계값 아래에서 감지되지 않을 수 있다. 따라서 OS 수준의 완벽한 절전 감지를 약속하지 않는다.
- `performance.now()`의 절전 중 동작은 환경 차이가 있고, 숨김 탭은 타이머 실행이 제한될 수 있다. 두 시간원을 함께 관측하는 이유다. [MDN: performance.now](https://developer.mozilla.org/en-US/docs/Web/API/Performance/now), [MDN: Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API).
- 진행 중 저장은 약 1초마다, 상태 전환·숨김·페이지 이탈 때 추가로 시도한다. 이탈 이벤트가 반드시 전달된다고 가정하지 않는다. [MDN: pagehide](https://developer.mozilla.org/en-US/docs/Web/API/Window/pagehide_event).
- 예기치 않은 종료의 복원값은 마지막으로 성공한 저장 시점이다. 정상 저장 중에는 약 1초 차이를 목표로 하되 브라우저 강제 종료·저장 실패에서도 정확한 종료 순간 복원을 보장하지 않는다.
- 저장용 벽시계 시각에서 닫혀 있던 시간을 빼거나, 이전 페이지의 `performance.now()` 값을 새 페이지에서 이어 쓰지 않는다.

## 7. 설정

하단의 작은 톱니바퀴로 어두운 설정 모달을 연다. 제목은 `설정`. 배경 화면과 같은 색 체계를 유지하고, 불필요한 설명은 줄인다.

| 항목 | 기본값 | 동작 |
| --- | --- | --- |
| 에반게리온 모드 | 끔 | 저장 시 테마 전환, 다음 실행에도 유지. 현재 타이머·D-day 유지 |
| 시계 초 표시 | 켬 | 시계의 작은 초만 표시/숨김 |
| D-day 표시 | 켬 | 날짜 차이 행 표시/숨김 |
| 목표 날짜 | 미설정 | 입력·수정·삭제 |
| 기본 타이머 | 25분 | 1~180분 정수 |
| 빠른 시작 1~4 | 10·20·25·60분 | 네 개의 분 단위 정수 입력, 순서 유지 |
| 완료 시각 알림 | 켬 | 일반 원형/화면 또는 에바 EMERGENCY의 30초 반복 효과를 공통으로 켜기·끄기 |
| 완료 소리 | 끔 | 일반 모드 완료 시 작은 소리 한 번. 에바 모드에서는 비활성·무음이며 기존 값 보존 |

- 빠른 시작은 항상 4개로 유지한다. 빈 값, 0, 음수, 소수, 180분 초과 입력은 저장할 수 없다. 중복 시간은 허용한다.
- 설정은 편집 초안을 두고 **저장 시 한 번에 적용**한다. 취소·Escape·닫기 버튼은 초안을 버린다. 배경 클릭으로는 닫지 않는다.
- 모달이 열려 있는 동안 포커스를 모달 안에 유지한다. 저장·취소로 닫으면 톱니바퀴로 포커스를 돌린다.
- `running`, `paused`, `completed`에서 기본 시간이나 빠른 시작을 바꾸어도 현재 실행의 총시간·남은 시간을 바꾸지 않는다. `idle`에서 기본 시간을 바꾸면 대기 시간이 새 기본값으로 바뀐다.
- 화면 표시 설정은 저장 즉시 적용한다. 완료 효과 도중 효과를 끄면 즉시 멈추며, 다시 켠다고 이전 완료 효과를 새로 시작하지 않는다.
- 원형/화면 모드는 메인 화면의 토글에서 선택한다. 이 토글은 설정 모달의 저장·취소와 별개로 즉시 적용·저장되며, 공통 완료 시각 알림 켜기·끄기 값을 바꾸지 않는다.
- 에바 모드에서는 원형/화면 토글을 숨기고 일반 모드로 돌아오면 이전 선택을 복원한다. 테마 변경으로 타이머를 새로 만들거나 이미 종료된 완료 효과를 재생하지 않는다.
- D-day 인라인 편집 중 설정을 열면 미저장 날짜 편집은 취소하고 저장된 날짜로 설정 초안을 만든다.
- 저장할 수 없는 환경에서는 설정 창에 `이 브라우저에서는 설정을 저장할 수 없습니다. 현재 창에서만 적용됩니다.`를 표시한다. 정상 화면에 기술 진단 문구를 상시 표시하지 않는다.

## 8. 로컬 실행과 저장

- 실행 파일은 `index.html`, `styles.css`, `eva.css`, `app.js`와 동봉 `assets/`다. 상대 경로의 CSS와 일반 `defer` 스크립트로 로드한다. 다른 폴더로 옮길 때 함께 복사한다.
- `file://`에서 불필요한 제약이 생기는 ES module 로딩, 로컬 JSON `fetch`, 외부 CDN·웹폰트·아이콘 패키지에 의존하지 않는다.
- 일반 화면은 시스템 sans-serif 폰트와 숫자용 tabular 설정을 사용한다. 에바 화면은 SVG 세그먼트 숫자와 로컬 `assets/eva-mincho.woff2`, 영상 질감용 `assets/eva-grain.svg`를 사용한다. 글꼴 출처와 전체 SIL OFL 1.1은 [FONT-LICENSE.txt](../assets/FONT-LICENSE.txt)에 동봉한다.
- 선택적 소리는 브라우저 Web Audio 등으로 짧게 생성한다. 사용자 시작/재개 조작 때 오디오 재생을 준비하고, 차단·실패해도 시각적 완료 처리는 정상 동작한다.
- 설정과 타이머 스냅샷은 버전이 있는 앱 전용 localStorage 키에 저장한다. 예: `simple-clock.settings.v1`, `simple-clock.timer.v1`.
- 설정 필드는 표시 옵션, 목표 날짜 문자열/null, 기본 분, 빠른 시작 배열, 시각 알림·소리 옵션, `alertMode`와 `evaMode`를 포함한다. `alertMode`는 `ring` 또는 `screen`만 허용한다. `evaMode`는 boolean이며 기본값은 `false`다. 기존 저장 데이터에 값이 없거나 유효하지 않으면 해당 필드를 기본값으로 복구하고 다른 유효 설정은 유지한다.
- 타이머 필드는 상태, 선택한 총시간, 남은 시간, 스키마 버전을 포함한다. 실행 중 저장 상태를 불러올 때는 `paused`로 변환한다. `idle`·`paused`·`completed`는 각각 그대로 복원한다.
- 새 데이터가 없을 때만 기본 타이머 시간으로 `idle`을 만든다. 잘못된 상태·음수·NaN·범위 밖 값·손상된 JSON은 검증하여 안전한 기본값으로 복구한다.
- 저장소 접근 자체부터 읽기·쓰기·파싱까지 예외를 처리한다. 저장이 불가능해도 현재 세션의 시계·타이머·설정은 사용할 수 있어야 한다.
- 다른 앱의 저장소를 지우는 `localStorage.clear()`는 사용하지 않는다. 여러 창 동기화는 범위 밖이며 같은 파일을 한 창에서 사용하는 것을 기본으로 한다.
- `file:` URL의 localStorage 동작은 표준으로 보장되지 않는다. 같은 브라우저 프로필·같은 파일 경로에서 검증하고, 파일 이동·브라우저 변경·시크릿 모드에서 설정 유지가 보장된다고 안내하지 않는다. [MDN: localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage).
- 설치형 앱, 백엔드, 서비스 워커, 강제 화면 켜짐 기능은 필요 없다.

2026-11-10 세그먼트 도형 및 화면 위 경보 수정 후 핵심 로직 14/14, 기존 브라우저 시나리오 18/18, 에바 검증 12/12 그룹을 통과했다. 브라우저 검증은 Linux Chrome 146의 실제 `file://`로 수행했으며 외부 HTTP(S) 요청·처리되지 않은 오류는 0건이다. 실제 30초 효과 종료와 경보 해제·스크롤 고정도 확인했다. 폰트 로드·누락 시 대체 표시는 초기 구현에서 검증했다. 항목별 범위·이전 검증 이력·실제 OS 절전 등 미검증 사항은 [작업 로그](WORKLOG.md)와 [에바 검증 범위](EVA_MODE_SPEC.md#9-검증-및-완료-기준)를 따른다.
